# ADR 001: Method for Webhook retrieval and IVR platform 

## Context: The IVR system needs to be hosted on a platform that can support the established requirements for it, taking into account user experience and cost. 

## Decision 
To build the real-time voice streaming endpoint (feat/ivr-twilio-websocket), I chose FastAPI with native asyncio WebSockets and in-memory asyncio.Queue buffers.

## Trade-off Analysis
- **Benefit:** Matches company standards, in terms of both computational costs and latency.
- **Drawback:** asyncio has a slightly unreliable storage methodology, where webhook streams are entirely depend on the host's machine.
