# ADR 006: SpeechBrain LID with Fixed LID fallback

## Context
Spoken language selection requires real audio language-ID. Early phases used a fixed/dev identifier so the state machine and Twilio wiring could be proven before model deps. Windows also needed a SpeechBrain lazy-import path patch (`\inspect.py` vs `/inspect.py`).

## Decision
- Prefer `speechbrain/lang-id-voxlingua107-ecapa` via `SpeechBrainLanguageIdentifier` when `IVR_USE_SPEECHBRAIN_LID` is true and deps load (`requirements-ivr-lid.txt`).
- Keep `FixedLanguageIdentifier` as hard fallback / smoke override (`IVR_LID_FORCE_LANGUAGE`).
- Convert SpeechBrain log-probs with `exp()` so confidence is usable against `IVR_MIN_LID_CONFIDENCE`.
- Warm LID at app lifespan so the first live call is not blocked on cold model load.

## Trade-off Analysis
- **Benefit:** Real multilingual ID on the same port as DTMF; Fixed LID keeps CI and Phase 9 smoke green without torch.
- **Drawback:** VoxLingua107 can confuse short telephony speech (e.g. French ↔ Breton); optional heavy deps; first download is large.
