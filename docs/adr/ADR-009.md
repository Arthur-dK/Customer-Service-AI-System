# ADR 009: Prefer major languages from LID top-k

## Context
Live barge-in tests showed SpeechBrain ranking low-resource lookalikes above the intended language (e.g. spoken French → `br` Breton at ~0.52 with `fr` second at ~0.29; earlier English noise → `lb`). Accepting the raw top-1 with a low `IVR_MIN_LID_CONFIDENCE` selected the wrong language.

## Decision
After VoxLingua107 scores, if the top label is not in a curated major-language set but a major language appears in the top-k with sufficient absolute probability and ratio to the top score, select that major language (`prefer_major_language_from_topk` in `services/ivr/lid.py`). Log remaps (`remapped_from`) for metrics/debug. Clear Twilio playback on VAD `speech_start` during barge-in so menu bleed is minimized before LID runs.

## Trade-off Analysis
- **Benefit:** Fixes observed French↔Breton (and similar) confusions without rejecting the utterance and forcing another DTMF round.
- **Drawback:** Heuristic — a rare genuine low-resource language could be remapped to a nearby major language if both appear in top-k.
