# ADR 004: Energy-based VAD for utterance boundaries

## Context
Language ID needs a complete spoken utterance, not a continuous stream. We need speech_start / speech_end without depending on a heavyweight cloud VAD during early phases.

## Decision
Use a simple RMS energy VAD (`services/ivr/vad.py`) on 8 kHz frames with configurable `rms_threshold`, `speech_start_ms`, and `speech_end_ms` (defaults via `IVR_VAD_RMS_THRESHOLD`). Emit buffered PCM16 on `speech_end` for LID.

## Trade-off Analysis
- **Benefit:** Fast, dependency-free, easy to unit-test and tune for telephony; works offline in the fake Twilio harness.
- **Drawback:** Can trigger on menu echo or noise if the threshold is too low; not as robust as neural VAD under heavy crosstalk.
