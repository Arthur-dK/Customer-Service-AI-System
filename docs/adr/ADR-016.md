# ADR 016: Handoff to placeholder turns on the Media Stream

## Context
Language selection already owns the Twilio Media Stream queues until a language is chosen. Placeholder turns (ADR-015) were proven only with in-memory buffers. The fake Twilio harness (ADR-010) is the right place to compose them before a live phone test.

## Decision
- After a successful `LanguageSelector.run`, drain leftover inbound frames and run `PlaceholderTurnEngine.run_on_queues` on the **same** inbound/outbound queues and `stop_event`.
- Do not change the language-selection state machine except this handoff in `app/api/ivr.py`.
- `turn_store` exposes last turns for pytest / the fake stream script (same idea as `selection_store`).
- Scripted STT and warmed phrase cache remain the CI engines; live smoke is Phase 7.

## Trade-off Analysis
- **Benefit:** End-to-end offline proof that “stop talking → canned reply media” uses the real WebSocket path.
- **Drawback:** The live number now also enters placeholder turns after language selection (menu + stub transcripts). Until a real STT is plugged in, unexpected speech maps to the “did not catch that” line.
